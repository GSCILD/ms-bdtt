# Appendix A. Simulator physical kernel

This appendix summarises the physical kernel of the MarineSim rotordynamic simulator. The shaft line is discretised with two-node Timoshenko beam elements of length l_e, each node carrying four degrees of freedom (two transverse displacements and two rotations). For an element with Young's modulus E, shear modulus G_s, second moment of area I, cross-sectional area A and shear correction factor κ_s = 0.9 (circular cross-section), the element stiffness matrix is the sum of a bending part and a shear part,

K_e = (EI / l_e³) · f_b(Φ) + (κ_s G_s A / l_e) · f_s(Φ) ,  Φ = 12 EI / (κ_s G_s A l_e²)    (A.1)

where f_b and f_s are the standard interpolation matrices and Φ is the shear-deformation parameter that distinguishes the Timoshenko element from the Euler–Bernoulli element. The consistent mass matrix combines the translational mass with the rotary inertia of the cross-section, and the gyroscopic matrix is assembled from the polar mass moment of inertia of each element. Bearings are modelled as speed-dependent stiffness and damping coefficients K_b(Ω) and C_b(Ω) obtained from short-bearing theory and corrected by the calibration factors k and c of Section 3.4.

Faults are injected as follows. An outer-race defect of angular width Δφ is represented by a periodic stiffness modulation at the ball-pass frequency, K_b(t) = K_b₀ [1 − η · Λ(t; BPFO)], where η ∈ [0, 0.3] is the severity parameter and Λ is a unit rectangular pulse train; a transverse crack of depth d produces a breathing stiffness reduction proportional to d/A; coupling misalignment introduces an asymmetric stiffness term that generates the 2× running-speed harmonic [26]; and imbalance is imposed as a rotating force of magnitude m_e e Ω². Table A.1 lists the nominal parameter values.

Table A.1. Nominal simulator parameters for the MAN 48/60CR-class propulsion plant.

| Parameter | Symbol | Value |
| --- | --- | --- |

# Appendix B. Finite element formulation

Assembling the element contributions over the n_e elements and applying the boundary conditions of the bearing supports gives the global system of Eq. (1). Modal reduction is applied to limit the computational cost: the response is projected onto the first n_m = 40 modes, which capture the dynamics up to 2 kHz, well above the fault characteristic frequencies of interest. The reduced system is integrated in time with the Newmark-β scheme (β = 0.25, γ = 0.5) at a fixed step of 1 × 10⁻⁴ s, and each operating point is simulated for 4 s, of which the last 2 s are retained to eliminate start-up transients. Fault characteristic frequencies are computed from the bearing geometry as BPFI = (n_b/2)(1 + d_b cos α / d_p) f_r, BPFO = (n_b/2)(1 − d_b cos α / d_p) f_r, BSF = (d_p / d_b)[1 − (d_b cos α / d_p)²] f_r and FTF = (1/2)(1 − d_b cos α / d_p) f_r, where n_b is the number of balls, d_b and d_p are the ball and pitch diameters, α is the contact angle and f_r is the shaft rotational frequency.

## C.1 Algorithm

Algorithm 1  Bayesian particle-filter calibration of the digital twin

Input:  simulator x_sim(θ), measured spectra Φ_meas, prior p(θ₀), N, σ

1:  draw θ₀⁽ⁱ⁾ ~ p(θ₀),  set w₀⁽ⁱ⁾ = 1/N,  i = 1, …, N

2:  for t = 1, 2, …, T do

3:      for i = 1, …, N do

4:          draw εₜ⁽ⁱ⁾ ~ N(0, Σ_θ)

5:          θₜ⁽ⁱ⁾ ← f(θₜ₋₁⁽ⁱ⁾) + εₜ⁽ⁱ⁾                ▷ propagate

6:          x̃⁽ⁱ⁾ ← x_sim(θₜ⁽ⁱ⁾)                      ▷ simulate

7:          Φ⁽ⁱ⁾ ← band-limited spectrum of x̃⁽ⁱ⁾

8:          wₜ⁽ⁱ⁾ ← wₜ₋₁⁽ⁱ⁾ · exp( − ‖Φ⁽ⁱ⁾ − Φ_meas‖² / 2σ² )   ▷ weight

9:      end for

10:      wₜ ← wₜ / Σᵢ wₜ⁽ⁱ⁾                          ▷ normalise

11:      ESS ← 1 / Σᵢ (wₜ⁽ⁱ⁾)²

12:      if ESS < N/2 then  systematic resampling of {θₜ⁽ⁱ⁾, wₜ⁽ⁱ⁾}

13:      θ̂ₜ ← Σᵢ wₜ⁽ⁱ⁾ θₜ⁽ⁱ⁾                        ▷ posterior mean

14:  end for

Output:  θ̂_T = [k̂, ĉ]ᵀ  (two-component structural correction state, fed back to Stage 1; severity is not a component of the filtered state)

## C.2 Proof of Proposition 2

Let the bridge mixture be D_b = Σ_k w_k B_k. By the triangle inequality of the H-divergence and the definition of the weighted bridge risk,

ε_t(h) ≤ ε_b(h) + d_{HΔH}( D_b, D_T ) + λ*_b ,  λ*_b = min_{h' ∈ H} [ ε_b(h') + ε_t(h') ]    (C.1)

Because the H-divergence is a metric on the symmetric difference hypothesis class, it is sub-additive over mixtures, d_{HΔH}(Σ_k w_k B_k, D_T) ≤ Σ_k w_k d_{HΔH}(B_k, D_T). Replacing the population risks by their empirical counterparts and applying a uniform-convergence argument over a class of VC-dimension d_VC with an effective sample size n_eff = (Σ_k w_k² / n_k)⁻¹ yields the estimation term Ξ(d_VC, Σ_k w_k² / n_k, δ) = O(√( d_VC log(2 n_eff) + log(2/δ) ) / n_eff ), which gives Eq. (15). Two consequences follow. First, for a fixed budget, the bound is minimised by concentrating the weights on the bridge domains with the smallest divergence to the target, which is what the attention mechanism learns to approximate. Second, the effective sample size decreases as the weights concentrate, so an excessively peaked attention distribution (small τ) degrades the estimation term; this trade-off explains the non-monotonic sensitivity to τ reported in Section 5.5.

## C.3 Sampling-allocation heuristic

Because the divergences d_k are not known in advance, demand-guided sampling replaces them by the computable demand map, N_k ∝ m(θ_o(k)). ## C.4 MMD estimator documentation and raw values

## E.2 Identifiability diagnostics for the [k, c] calibration state

Prior-mismatch classification results do not establish identifiability, so three controlled diagnostics are reported for the two-component calibration state of Section 3.4.

Parameter recovery. A grid of known true corrections (k*, c*) spanning ±20 % around nominal is simulated through the Stage-1 kernel; for each grid point, synthetic healthy-condition observations are generated with the sensor and ambient noise of Section 3.2, and the particle filter of Algorithm 1 is run from the nominal prior. Identifiability is quantified by the correlation and root-mean-square error between recovered and true values across the grid, reported separately for k and c.

Posterior predictive checks. For each grid point, the posterior predictive distribution of the band-limited spectral features is compared with the observed synthetic features using the MMD of Eq. (12) and visualised for systematic residual structure; a well-calibrated posterior produces predictive features statistically indistinguishable from the observations.

Operating conditions. 0 HP (1797 r/min), 1 HP (1772 r/min), 2 HP (1750 r/min), 3 HP (1730 r/min).

Labels, exclusions, preprocessing. Labels are the provider's fault categories and diameters. Exclusions: none beyond the fan-end/48 kHz restriction; no record is shared between scenarios. Preprocessing: per-record z-normalisation computed on the training partition only (Section 4.4); sliding windows of 2048 samples; window partitions inherit the parent record (S2 derivative inheritance, Section 4.2.2). Approximately 30,000 windows; per-class counts in the manifest.

## F.2 XJTU-SY

Files. Run-to-failure trajectories under the three provider conditions, organised as 35Hz12kN, 37.5Hz11kN and 40Hz10kN directories (corresponding to 2100, 2250 and 2400 r/min), each containing per-bearing subdirectories with sequentially numbered 1.28 s segments (32,768 samples per file, sampled every minute).

Channels. Two accelerometers (horizontal-radial and axial); native sampling rate 25.6 kHz; the horizontal-radial channel is used.

Operating conditions. 2100 r/min with 12 kN; 2250 r/min with 11 kN; 2400 r/min with 10 kN. (Corrected from the erroneous 2100/1500/900 r/min of the previous version; see Section 4.1.)

Labels, exclusions, preprocessing. Labels follow the three-step degradation-boundary protocol of Section 4.2.3: healthy before the +3σ onset index; terminal damage mode (from the provider's inspection report) after the +5σ definite-damage index; the ambiguous interval between the two thresholds is excluded. Trajectories whose terminal inspection reports combination damages are excluded from S3 (no CWRU counterpart). Preprocessing: window length 2048; per-trajectory baseline statistics computed within the training partition only. Labelled pool after the protocol: approximately 28,000 windows; per-trajectory and per-class counts are listed in the manifest (Table F.2 summary).

Table F.2. S3 label budget under the degradation-boundary protocol: the audited quantities and where each is recorded.

| Audited quantity | Definition | Where it is recorded |
| --- | --- | --- |
| Run-to-failure trajectories used | trajectories whose terminal inspection reports a single-fault mode and which pass the onset test of Section 4.2.3 | manifest_S3.csv, column `trajectory` with `partition = train/test` |
| Trajectories excluded | terminal inspection reports a combination damage, for which no CWRU counterpart exists | manifest_S3.csv, column `trajectory`, excluded flag |
| Healthy windows | windows before the +3σ onset index t* | manifest_S3.csv, column `label = healthy` |
| IR / OR / roller windows | windows after the +5σ definite-damage index t**, labelled with the inspected terminal mode | manifest_S3.csv, column `label` |
| Excluded ambiguous windows | the interval (t*, t**], neither confidently healthy nor confidently faulted | manifest_S3.csv, column `excluded = 1` |

The counts themselves are produced by the labelling script from the public dataset and are regenerated with the archive; they are not quoted here because the protocol, not a particular count, is the object of the audit.

## F.3 Paderborn

Files. Real-damage and healthy bearings only: healthy K001–K006; real outer-race damage KA04, KA15, KA16, KA22, KA30; real inner-race damage KI04, KI14, KI16, KI18, KI21; real combined damage KB23, KB27, KB29, KB33. Artificial-damage bearings are excluded (machining signatures differ physically from service-type damage). File naming follows the provider convention KXXX_YYZZ (bearing code and measurement index); v2.0.0 of the dataset is used.

Channels. Housing-vibration accelerometer mounted in the main radial-load direction; native sampling rate 64 kHz. (The "twelve accelerometer channels" of the previous version were incorrect; the provider records one vibration channel together with motor-current and operating-parameter channels.)

Operating conditions. OC0: 1500 r/min, 0.7 N·m, 1000 N; OC1: 900 r/min, 0.7 N·m, 1000 N; OC2: 1500 r/min, 0.1 N·m, 1000 N; OC3: 1500 r/min, 0.7 N·m, 400 N. Twenty measurements of 4 s per bearing and condition.

Labels, exclusions, preprocessing. Labels: healthy, inner-race, outer-race, combined (four classes; the early-stage damage categories are excluded, which accounts for the reduction of the window pool from 14,700 candidates to 12,600 windows, Section 4.1). Preprocessing: window length 2048 with 50 % overlap inside a measurement; windows overlapping measurement boundaries are discarded; per-measurement z-normalisation computed on the training partition only. Bearing-specimen-level partitioning: all recordings of one bearing, across all conditions, remain in one partition (Section 4.4).

## F.4 SEU

Files. Gearbox (gear-fault) subset of the drivetrain dynamics simulator dataset: five classes (healthy; chipped tooth; missing tooth; root fault; surface wear) × two conditions, stored per class and condition as separate recording files; both conditions are used (20 Hz–0 V as source side, 30 Hz–2 V as target side in the cross-condition construction of S4's within-dataset checks, and both as S4/S5 sources).

Channels. Eight channels per recording (motor vibration; planetary-gearbox x, y, z; motor torque; reduction-gearbox x, y, z); native sampling rate 5120 Hz. The three reduction-gearbox channels and the motor-vibration channel are used.

Operating conditions. 20 Hz input speed with 0 V brake command (0 N·m); 30 Hz with 2 V (7.32 N·m). (The "three load levels of 0, 10 and 20 N·m at 10 kHz from proximity probes" of the previous version were incorrect; see Section 4.1.)

Labels, exclusions, preprocessing. Labels are the provider's class files; no provider-side exclusions apply. Preprocessing: window length 2048 with 50 % overlap; windows overlapping file boundaries are discarded; per-file z-normalisation computed on the training partition only. Approximately 12,000 windows; per-class counts in the manifest.

## F.5 SPFD composition and supports

SPFD is generated by MarineSim under the sea-state model of Section 4.1; the generation manifest fixes the per-group class supports of the test partition, which enter the sample-weighted OA of Section 5.4.

Table F.5. SPFD group composition: the audited structure of the test partition and where the exact supports are recorded.

| Group | Construction | Test support recorded in |
| --- | --- | --- |
| Bearing wear (early, moderate, severe) | three severity levels of the simulated outer-race defect, mapped from the laboratory defect-area fractions of Table F.6 | generation manifest, column `group`, `split = test` |
| Shaft misalignment | asymmetric bending stiffness producing the 2× running-speed component | generation manifest |
| Propeller cavitation | broadband excitation with no discrete characteristic frequency | generation manifest |
| Gear pitting | localised tooth-surface loss at the gear-mesh frequency | generation manifest |
| Composite faults | pairwise combinations of the above | generation manifest |
| Normal-condition calibration pool | healthy-condition simulations used only for Bayesian calibration; held out from the test partition by construction | calibration manifest, `split = calibration` |

The test partition comprises approximately 5 000 samples (Section 4.1). Because the groups have unequal supports, the sample-weighted overall accuracy of Section 5.4 (76.0 %) and the unweighted mean of the per-group accuracies (74.5 %) differ; the exact supports are read from the generation manifest, which the regeneration script applies when it recomputes both quantities.
